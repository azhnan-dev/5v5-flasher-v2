langkah flashing ke epon

1. umum nya modem yg masuk itu ip nya 192.168.18.1.
user Epadmin
pass adminEp
kadang juga 192.168.100.1, kalau 192.168.100.1
user telecomadmin
pass admintelecom


2. setelah login, upload file default 1_1010.xml di menu settings, maintenence upload configruation file
3. setelah modem selesai reboot dan booting. buka TOOLS FLASHER.exe. 
4. pilih opsi flash > network pastikan masuk ke 192.168.100.0/24 / sesuai lan laptop mu. Ont version pilih 2 - R022.bin.
5. klik flash dan tunggu finsih. kalau sudah stop
6. restart modem 1-2 menit boot up
7. run 3 - EquipmodeR022.bat (tunggu selesai dan restart)
7. router akan restart 1-2 menit 
7. run 4 - Epon Mode.bat
8. restart dan selesai
